# MySQL Practice

Учебный монорепозиторий с практическими заданиями по MySQL на основе базы данных Northwind.

## Technologies

- MySQL
- MySQL Workbench
- SQL
- Git & GitHub

## Projects

### 01 — SQL Basics

Основы SQL: `SELECT`, `FROM`, `WHERE`, фильтрация данных и логические операторы.

### 02 — SQL Functions

Практика работы с SQL-функциями, строками, вычисляемыми столбцами, сортировкой и обработкой `NULL`.

### 03 — Date and Time Functions

Работа с датами и временем: `CURDATE()`, `DATEDIFF()`, `WEEKDAY()`, `DAYNAME()`, `DATE_ADD()`, `CAST()`.

## Database

Практические задания выполняются на учебной базе данных Northwind.

Репозиторий содержит SQL-запросы для чтения и анализа данных без изменения исходной базы.

## Learning Goals

- Изучение синтаксиса SQL
- Фильтрация и сортировка данных
- Работа со встроенными функциями MySQL
- Обработка `NULL`
- Практическое решение задач на основе бизнес-кейсов
- Организация учебных проектов с помощью Git и GitHub
